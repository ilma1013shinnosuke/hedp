# 人感センサーとSmart LEDZの連携

## 目的

SwitchBotの通常の人感センサーが検知したら、指定したSmart LEDZのシーンまたは
スケジュールを直ちに選びます。最後の検知から設定時間が経過したら、別に指定した
シーンまたはスケジュールへ移ります。

## 設定できること

- 対象となる通常人感センサー
- 最後の検知から終了動作までの秒数（1秒から24時間）
- 検知時の対象照明グループ
- 検知時に選ぶシーンまたはスケジュール
- 終了時の対象照明グループ
- 終了時に選ぶシーンまたはスケジュール

例は
`config/examples/motion_smartledz_automation.example.json`
にあります。家庭固有の識別子は安全な別名へ置き換え、Gitへ入れません。

## 動作ルール

1. 通常人感センサーの正常な検知イベントだけを受け付けます。
2. 最初の検知で開始動作を1回だけ依頼します。
3. 点灯中の再検知では開始動作を繰り返さず、終了期限だけを延長します。
4. 最後の検知から設定時間が経過すると、終了動作を1回だけ依頼します。
5. 同じイベントの再配信は無視します。
6. 人が照明を操作した場合は待機中の終了動作を取り消し、人の操作を優先します。
7. 再起動後は古い待機状態を復元して盲目的に操作しません。

## 層の分離

第3層は、検知と時刻から「どのシーン／スケジュールを選ぶか」だけを判断します。
第4層は、対象、権限、状態の鮮度、重複、安全条件を確認してSmart LEDZへ送り、
実際の状態を再取得して結果を確認します。

## 現在の制約

- この段階はオフラインの判断機能と設定形式です。実機操作は行いません。
- ほぼ遅延なしにするには、1時間ごとの定期取得ではなく、BLEイベントまたは安全に
  管理されたWebhookなどのイベント経路が必要です。
- Smart LEDZのシーン実行は既存の検証計画を利用できます。
- スケジュール選択は型として扱えますが、実機コマンドと結果確認が未検証のため、
  現在のExecution層では安全に停止します。検証が完了するまで成功扱いしません。
